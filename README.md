# 🚀 Harekam Kaur — Portfolio Website

A modern and interactive **personal portfolio website** built with **React, TypeScript, and Three.js**.

The portfolio combines immersive **3D visuals**, smooth animations, and a responsive user interface to create an engaging experience while showcasing my skills, projects, and work. ✨

## 🔗 Links

🚀 **[Live Demo](https://portfolio-updated-one-eta.vercel.app/)**
💻 **[GitHub Repository](https://github.com/harekamk/Portfolio_Updated)**

---

## ✨ Features

* 🌐 **Interactive 3D Experience** — Immersive 3D scenes and models powered by Three.js.
* 🎮 **Physics-Based Interactions** — Interactive elements using React Three Cannon and Rapier.
* ✨ **Visual Effects** — Post-processing effects for a polished and modern experience.
* 🎬 **Smooth Animations** — Scroll and entrance animations powered by GSAP.
* 📱 **Fully Responsive** — Optimized for desktop, tablet, and mobile devices.
* ⚡ **Fast Performance** — Built with Vite for a fast development and production experience.
* 📊 **Analytics Integration** — Visitor analytics powered by Vercel Analytics.
* 🔒 **Type-Safe Development** — Built with TypeScript for improved code reliability.
* 🎨 **Modern UI** — Clean, visually engaging, and interactive design.

## 📦 Getting Started

### ✅ Prerequisites

Make sure you have the following installed:

* 🟢 **Node.js** — Version 18 or higher recommended
* 📦 **npm** — Comes with Node.js

### 📥 Installation

Clone the repository:

```bash id="0ce5yz"
git clone https://github.com/harekamk/Portfolio_Updated.git
```

Move into the project directory:

```bash id="e2k20b"
cd Portfolio_Updated
```

Install the dependencies:

```bash id="v0myr0"
npm install
```

---

## 💻 Running Locally

Start the development server:

```bash id="u6c6cs"
npm run dev
```

The application will usually be available at:

```text id="h7cmz0"
http://localhost:5173
```

---

## 🏗️ Building for Production

Create a production build:

```bash id="rnxhba"
npm run build
```

The project is built using TypeScript's project build followed by a Vite production build.

## 👀 Preview Production Build

To preview the production build locally:

